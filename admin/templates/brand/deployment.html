Deployment

What the proxy in front of this panel is doing, and whether the three settings that govern it agree with each other. Open this page through the proxy you are configuring and read the table below: it is this request, as it arrived.

This page changes nothing. nginx renders its configuration once, when its container starts, so changing a value means re-rendering and reloading it — which is not something a web page may be able to do to its own container. README.md has the docker exec sequence for trying a setting without a rebuild, including the part where the change does not survive the next start.
