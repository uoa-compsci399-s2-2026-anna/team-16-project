One IPv4 or IPv6 address — no port, no range, no leading zeroes. This panel cannot tell you what to type here. It never stores or displays a caller's address, by design, so the value has to come from outside: your hosting platform's or reverse proxy's access log, or an alert from whoever can see the traffic.

This is what the blocklist screen and the audit log show in place of the address, so do not write the address itself here — doing so would defeat the reason only a hash of it is stored.

Blank means permanent, until unblocked by hand. Blocking an address that is already blocked replaces its reason and duration — leaving this blank on a re-block removes any expiry the earlier block had, rather than extending it.
