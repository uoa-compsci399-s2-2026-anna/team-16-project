What this does

  • The placeholder-data warning disappears from every public result and every export calculated from this set — the results screens, the methodology page and every file a visitor downloads. It is the only thing telling them the numbers are not real, and a visitor cannot dismiss it while it is there.
  • {% if is_published %} This set is published, so it happens immediately, on the next calculation anybody runs. {% else %} This set is not published, so nothing the public sees changes today. It changes the moment somebody publishes this set — and Publish does not ask again. {% endif %}
  • Nothing else about this set changes. Not one factor value, not the version label, not the results anybody has already been shown.
  • The change is recorded in the audit log against your name, with the value it went from and the value it went to.
  • It is reversible: Flag as placeholder data on the factor-set list puts the warning straight back, in any status, without asking for anything.

Clear it when every number in this set is real

It is all or nothing — the warning cannot say that forty rows are measured and twelve are still borrowed. The Data quality note on each factor row is where that belongs.

The ordinary sequence is to publish the real numbers with this flag still set, leave them running for a day or two and check them in front of real use, and clear it only then. There is no need to clone this set to do it: cloning would make a new version label for a change in which not one factor value differs.
