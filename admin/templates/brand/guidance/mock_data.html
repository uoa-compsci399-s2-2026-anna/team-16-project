Placeholder numbers, and the warning that goes with them

The calculator is running on placeholder factors. They are the right shape and the wrong values, and nothing calculated from them is a scientific result.

Is Mock on a factor set is what says so — the tick on its form, and the column of the same name on this list. While it is ticked on the published set, every results page, the methodology page and every file a visitor exports carries a warning they cannot dismiss. Untick it and all of those disappear together — this one tick is the only thing holding them up.

When the client supplies the real factors:

  1. Clone the published set. The clone is a draft, and it is still ticked as mock.
  2. Replace the numbers in the draft — upstream factors, downstream factors, constants, equivalences. Put the source of each figure in its Source note as you go: that text is published alongside the factors themselves, and it is the only place the calculator can say where a number came from.
  3. Untick Is Mock on the draft, once every number in it is real. It is all or nothing — the warning cannot say that forty rows are measured and twelve are still borrowed. The Data quality box on each row is where that belongs.
  4. Run Try a scenario against the draft, and Compare with published, before publishing anything.
  5. Publish. The warning stops appearing for the public at that moment.

The one sequence to avoid is unticking Is Mock on a half-finished draft and publishing it to see how it looks: the public sees it too, with placeholder numbers and nothing on the page saying so.
