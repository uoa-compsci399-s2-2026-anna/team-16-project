Placeholder numbers, and the warning that goes with them

{{ _("What the Is Mock flag does, and how to turn it off once the real numbers are in") }}

The calculator is running on placeholder factors. They are the right shape and the wrong values, and nothing calculated from them is a scientific result.

Is Mock on a factor set is what says so — the column of that name on this list. While it is set on the published set, every results page, the methodology page and every file a visitor exports carries a warning they cannot dismiss. Clear it and all of those disappear together — this one flag is the only thing holding them up.

It is not a tick on the edit form, and the two directions are not the same size. A checkbox sitting on a form is something you can take off by accident while you are changing a version label, and the form has nowhere to ask whether you meant it. So:

  • Flag as placeholder data adds the warning. It works on a draft, on the published set and on an archived one, it asks for nothing, and it takes effect at once. If you have any doubt about the numbers under the live set, press it — being wrong this way costs a warning on a page that did not need one, and the other action takes it straight back off.
  • Clear placeholder flag removes the warning. It asks for your password or a code from your authenticator first, and it records who cleared it and when. Being signed in is the one thing somebody who had taken your session would also have.

When the client supplies the real factors:

  1. Clone the published set. The clone is a draft, and it is still flagged as mock.
  2. Replace the numbers in the draft — upstream factors, downstream factors, constants, equivalences. Put the source of each figure in its Source note as you go: that text is published alongside the factors themselves, and it is the only place the calculator can say where a number came from.
  3. Run Try a scenario against the draft, and Compare with published, before publishing anything.
  4. Publish, with the flag still set. The public gets the real numbers and the warning at the same time, which is the honest state while nobody has checked them in front of real use yet.
  5. Leave it a day or two and watch it. Then select the published set and choose Clear placeholder flag. The warning stops appearing at that moment.

You do not need to clone a set to clear its flag. That used to be the only way, and it was the wrong shape: it made a new version label for a change in which not one factor value differs, while every calculation recorded in between stayed stamped with the old version — a break in the version history invented by the panel rather than by the numbers.

Clear it only when every number in the set is real. It is all or nothing — the warning cannot say that forty rows are measured and twelve are still borrowed. The Data quality box on each row is where that belongs.
