Only the `topbar` block is replaced. THERE IS NO LANGUAGE SWITCHER, AND THAT IS THE DECISION THIS FILE RECORDS. A dropdown writing a `kaicalc_lang` cookie stood here until the repository owner ruled it out: the language is negotiated per request from `Accept-Language`, nothing is persisted, and there is no control to operate. `?lang=` still forces a language for one request - for testing, screenshots and support - but nothing on the page emits it. sqladmin ships a switcher of its own in this block, and it is not used either: it renders only when an `I18nConfig` is passed to `Admin()`, and that path requires `babel` and offers only the five locales sqladmin compiled into its own package.
