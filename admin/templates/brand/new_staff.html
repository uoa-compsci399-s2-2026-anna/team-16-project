What happens next

  1. The account is created and a password is generated for it. That password is shown to you once, on the next page.
  2. You hand it over in person or by phone. There is no email in this system, deliberately — nothing is sent to anybody.
  3. At their first login they are made to choose their own password and then to set up an authenticator app. Neither step can be skipped, and until both are done the account can reach nothing.

If you lose that password before handing it over — a closed tab, a crash — the account is not lost with it. Nobody can log in as it, and you can issue a new password from the accounts screen at any time using Issue a new password. You never need to create a second account for the same person.
