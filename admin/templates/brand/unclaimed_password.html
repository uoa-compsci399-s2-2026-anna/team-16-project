What this shows, and what it costs

  • The password this system last gave the account — the one it was created with, or the replacement you issued — and only while nobody has claimed it. It disappears from here permanently the first time that person sets a password of their own, which the panel forces at their next login.
  • It is a working credential. On an account that has not enrolled an authenticator yet it is the whole of the protection: whoever holds it can log in, set a password, and enrol their own phone as the second factor. Treat it exactly as you would treat the page that first showed it.
  • Every time this is shown it is written to the audit log, naming you, the account and the time. The password itself is never written there.
